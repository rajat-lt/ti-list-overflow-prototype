# ti-list-overflow-prototype

Working prototype of the horizontal-overflow fix for Test Instance list rows in LambdaTest Test Manager. Current layout next to the proposed one, at 1280 px and 1512 px, with worst-case data and a live pass/fail check.

Live: https://rajat-lt.github.io/ti-list-overflow-prototype/

Run locally: open `prototype/index.html` in a browser. No build step, no dependencies beyond the Lucide icon CDN.

Controls, checks, data sources and open items: [prototype/README.md](prototype/README.md).
